感染症 電話問診・連絡管理システム（infectcare）

2026.11 ｜ 個人開発

保健所での感染症対応を想定して設計・開発したWebシステムです。患者登録、電話問診、接触希望者への連絡記録を一つの画面で管理できます。新しい感染症が出た場合も、管理者が画面から症状項目を追加するだけで使い続けられます。

  • 患者が自分のスマートフォンから情報を入力できる、一回限りの入力リンク
  • 住民登録番号をAES-256-GCMで暗号化して保存し、一覧では一部をマスク表示
  • 管理者・医師・看護師・一般職員の権限分け、閲覧履歴を残す監査ログ
  • 画面の韓国語／日本語切り替え（messages.propertiesによる多言語対応）
  • Java 21
  • Spring Boot
  • Spring Security
  • MyBatis
  • Thymeleaf
  • Oracle
  • HTML / CSS / JavaScript
